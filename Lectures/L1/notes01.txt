#---Level03: Defining function---#

def hello():
    print("Hello,")

name= input("Enter your name")
hello()
print(name)


!Other approach!

def hello(to= "world"):
    print("Hello,", to)

name= input("Enter your name")
hello(name)

-->What happens?
Python looks at the function def hello(to="world").
You passed "Joy".
Python says: "Okay, the user provided a value. I will throw away 'world' and put "Joy" into the variable to."

The function runs: print("Hello,", "Joy").
Result: Hello, Joy
